🌐 ACESSAR A APLICAÇÃO:

   1. Abra seu navegador (Chrome, Firefox, Edge, etc.)
   2. Digite na barra de endereço: http://localhost:5000
   3. Você verá a interface do Gerador de Flashcards

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📤 COMO USAR:

   1. Prepare seu arquivo JSON (veja exemplo.json)
   2. Arraste o arquivo para a área de upload OU clique para selecionar
   3. Clique em "Gerar Deck Anki"
   4. Aguarde o processamento
   5. Clique em "Baixar Deck APKG"
   6. Importe o arquivo .apkg no Anki

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📝 FORMATO DO JSON:

{
  "nome_deck": "Nome do seu baralho",
  "cards": [
    {
      "pergunta": "Sua pergunta aqui?",
      "resposta": "Sua resposta aqui"
    },
    {
      "pergunta": "Outra pergunta?",
      "resposta": "Outra resposta"
    }
  ]
}
