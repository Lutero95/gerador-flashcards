🎯 PASSO A PASSO SIMPLIFICADO:

1️⃣  CRIAR REPOSITÓRIO NO GITHUB
    
    → Acesse: https://github.com/new
    → Nome: gerador-flashcards-anki
    → Clique em "Create repository"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2️⃣  SUBIR O CÓDIGO (Execute no terminal):

    git init
    git add .
    git commit -m "Deploy para Vercel"
    git branch -M main
    git remote add origin https://github.com/SEU_USUARIO/gerador-flashcards-anki.git
    git push -u origin main

    ⚠️ Substitua SEU_USUARIO pelo seu usuário do GitHub!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3️⃣  DEPLOY NO VERCEL

    → Acesse: https://vercel.com
    → Clique em "Add New" → "Project"
    → Selecione seu repositório do GitHub
    → Clique em "Import"
    → Clique em "Deploy"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4️⃣  PRONTO! 🎉

    Você receberá uma URL tipo:
    https://seu-projeto.vercel.app

    Compartilhe com qualquer pessoa no mundo! 🌍

    Sempre que fizer mudanças no código, execute:

    git add .
    git commit -m "Descrição das mudanças"
    git push

    O Vercel atualiza automaticamente! ✨
